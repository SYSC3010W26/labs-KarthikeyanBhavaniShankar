# SYSC3010 – Computer Systems Development Labs

This repository contains my completed laboratory work for **SYSC3010 (Winter 2026)** at **Carleton University**.

Each lab is organized in its own folder and includes source code, screenshots, and required deliverables as specified in the lab instructions.

---

## 🧪 Labs Overview

### **Lab 1 – SenseHAT & Networking**
- Sensor data collection
- Network configuration
- Python scripts and screenshots

### **Lab 2 – Databases & JSON**
- SQLite database creation
- Sensor data logging and visualization
- OpenWeatherMap API integration

### **Lab 3 – IoT & Firebase**
- Firebase Realtime Database
- Cloud data upload from Raspberry Pi
- Python-based IoT integration

### **Lab 4 – GPIO & Hardware**
- LED control using GPIO
- Breadboard and schematic (Fritzing)
- Python GPIO control script

### **Lab 5 – Pi Camera & Computer Vision**
- Raspberry Pi Camera (rpicam)
- OpenCV setup
- Edge detection using Python
